📘 Como importar a planilha no Conta Azul

A planilha gerada por este conversor segue rigorosamente a estrutura oficial do Conta Azul:

Passo a passo no Conta Azul:
  1. No Conta Azul, acesse o menu Financeiro > Extratos e Contas (ou Movimentações).
  2. Selecione a conta corrente bancária desejada.
  3. Clique na opção Importar Extrato / Planilha.
  4. Envie o arquivo .xlsx ou .xls gerado aqui pelo aplicativo.
  5. Confirme a importação. Todas as datas, valores de débitos/créditos e descrições serão sincronizados automaticamente!

✔️ Regra de 3 Datas: Conforme solicitado, as 3 colunas (Data de Competência, Data de Vencimento e Data de Pagamento) são preenchidas com a data exata de cada movimentação.

✔️ Múltiplos Documentos: Você pode enviar 1, 5 ou mais extratos de uma só vez para gerar uma planilha unificada ou baixar individualmente.
